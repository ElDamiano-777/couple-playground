# Together

**Ваше маленькое пространство для двоих.**

1. [Открой приложение](https://eldamiano-777.github.io/couple-playground/).
2. Чтобы добавить значок на iPhone, открой ссылку в Safari: «Поделиться» → «На экран „Домой“».
3. В своей беседе с помощником нажми микрофон на клавиатуре и расскажи, что хочешь изменить. Можно по-русски, по-английски или по-немецки.
4. Дождись ссылки от помощника и посмотри, что получилось.

**Например:** «Хочу, чтобы главная страница была нежно-розовой» или «Добавь место для наших идей».

Для пробного входа выберите Masha или Damian и введите пароль, который задал Damian. Покупки у этих двух пробных аккаунтов общие; подтверждение почты не нужно. Не добавляйте в пробное пространство личные или чувствительные сведения.

Отдельный вход через личную почту также сохранён.

Личные заметки можно сохранять только на своём телефоне. Партнёр их пока не видит. Если удалить данные браузера, заметки тоже удалятся.

Настройку доступа к помощнику один раз завершает Damian. После этого не нужны команды, установка программ или самостоятельная публикация.

# Stand der sanften Begleitung

Optionale Merkliste für passende Begleithinweise und abgelehnte Vorschläge. Nur bei Bedarf lesen oder mit einem ohnehin nötigen Commit aktualisieren; keine Routinepflicht und kein eigener Veröffentlichungsschritt. Nur allgemeine Themennamen eintragen.

## Schon dran gewesen

- [ ] Sicher ausprobieren und zurücknehmen
- [ ] Ergebnis beschreiben
- [ ] Eine Sache nach der anderen
- [ ] Selbst prüfen und konkret rückmelden
- [ ] Der Agent kann sich irren
- [ ] Frischer Chat
- [ ] Skill
- [ ] Wer nutzt es wann
- [ ] Kleinste Version zum Ausprobieren
- [ ] Alltag des Partners und Sichtbarkeit
- [ ] Zurückblicken

## Nicht erneut vorschlagen

- Noch nichts.
